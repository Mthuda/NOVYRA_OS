# NOVYRA OS

NOVYRA OS is a structured Python-based decision intelligence and automation project.  
The goal is to build a modular system that can ingest data, process it, score it, explain it, and eventually automate approved actions in a controlled way.

## Project Purpose

NOVYRA OS is being developed as a real engineering project, not a throwaway script.  
The system is designed to be:

- modular
- documented
- testable
- secure
- version-controlled
- easy to extend

## Current Project Focus

We are currently in **Phase 2: Core Application Skeleton**.

This phase establishes:

- the Python package structure
- configuration handling
- logging setup
- testing structure
- reusable application entry points
- project standards
