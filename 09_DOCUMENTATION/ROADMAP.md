# NOVYRA OS Development Roadmap

**Project:** NOVYRA OS

**Current Version:** v0.3.0

**Current Phase:** Phase 3 – Persistence Foundation (Completed)

---

# Project Vision

NOVYRA OS is an opportunity intelligence platform that helps users discover,
manage, analyse and act on opportunities from multiple sources through a
modular backend powering multiple user interfaces.
