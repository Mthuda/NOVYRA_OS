# NOVYRA OS Changelog

All notable changes to NOVYRA OS are documented in this file.

phase represents a stable version of the system.

# Version 0.3.0
## Phase 3 – Persistence Foundation

Release Date:
July 2026

### Added

- SQLite database support
- Database configuration module
- SQLite connection management
- Database schema initialization
- SQLite Opportunity Repository
- Persistent opportunity storage
- Database verification utility
- Repository persistence integration tests
- Database infrastructure package exports

### Changed

- Opportunity Service now supports SQLite-backed persistence
- Project stage updated to "Phase 3 – Persistence Foundation"

### Testing

- 67 automated tests passing

- Database creation verified
- SQLite persistence verified
- Repository reopen persistence verified
